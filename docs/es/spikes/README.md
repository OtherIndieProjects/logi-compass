# Pruebas de concepto (spikes)

Carpeta de experimentos técnicos usados al elegir librerías y patrones.  
El código de referencia está en `tools/spikes/`.

| Id | Tema | Conclusión en producto |
| --- | --- | --- |
| S1 | Grid Avalonia | Cliente Avalonia en uso |
| S2 | Argon2id | Hash de contraseñas en Identity |
| S3 | RLS + EF Core | Aislamiento portal / cliente |
| S4 | Tiempos `pg_dump` | Orientación de backups |
| S5 | Publicación single-file | Host publicable win/linux |
| S6 | Blazor BFF / CSP | Portal Blazor separado |
| S7 | Auditoría + crypto-shred | Cadena de auditoría |
| S8 | Almacén seguro de tokens | Tokens en cliente escritorio |

Las decisiones formales están en `docs/adr/`. Los spikes no sustituyen las guías de usuario.
