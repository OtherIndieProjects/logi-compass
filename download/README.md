# Descarga Windows (compilado)

El paquete listo para ejecutar **no** vive en el historial del repositorio (es grande).
Se publica en la **Release** de GitHub correspondiente.

- Última release: https://github.com/OtherIndieProjects/logi-compass/releases/latest  
- Asset típico: `LogisticSolution-Windows-x64.zip`

## Instalación rápida

1. Descargue el ZIP de la release.
2. Clic derecho → Extraer todo…
3. Coloque la carpeta en el Escritorio como `LogisticSolution` (o el nombre que prefiera).
4. Ejecute `Iniciar Servidor.bat` y luego `Iniciar Cliente.bat`.
5. Guías PDF incluidas en `docs\` dentro del ZIP.

Este paquete **no incluye contraseñas**. Configure PostgreSQL y el administrador en su máquina.
